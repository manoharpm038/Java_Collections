# Java Collections - Practice Problems & Solutions

## 📌 Project Overview

This project contains **solutions to various Java Collection Framework problems** with clear explanations.
It is designed to help beginners and intermediate learners understand how different collection classes work internally and how to use them effectively.

---

## 📚 Topics Covered

### 1. List Interface

* ArrayList
* LinkedList
* Vector

### 2. Set Interface

* HashSet
* LinkedHashSet
* TreeSet

### 3. Queue Interface

* PriorityQueue
* ArrayDeque

### 4. Map Interface

* HashMap
* LinkedHashMap
* TreeMap

---

## 🧠 What You Will Learn

* Difference between List, Set, and Map
* How to store and retrieve data
* Handling duplicates and ordering
* Internal working concepts (basic level)
* Iteration techniques (for loop, iterator, foreach)
* Sorting and searching

---

## 🛠️ Problem Types Included

* Add, remove, and update elements
* Find duplicates in a list
* Count frequency of elements
* Sort collections (ascending/descending)
* Convert List to Set and vice versa
* Use of Comparator and Comparable
* Real-time scenarios using collections

## 💡 Example Explanation

### Problem: Find Duplicate Elements in a List

**Approach:**

* Use HashSet
* Add elements to set
* If element already exists → duplicate found

**Code Logic:**

* Set does not allow duplicates
* So repeated elements can be detected easily

## 🚀 Key Concepts Explained

### 🔹 ArrayList

* Dynamic array
* Allows duplicates
* Maintains insertion order

### 🔹 HashSet

* No duplicates allowed
* No guaranteed order

### 🔹 HashMap

* Stores key-value pairs
* Keys are unique
